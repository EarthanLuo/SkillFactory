# Evolution

## Trigger

`reverse-experience` 在提取网页替身经验时丢失了“Astar 模型”限定，并把局部性能结果扩展成了方案级判断。

## Problem

旧指导语要求识别情境约束和失败边界，但没有明确规定摘要来源主张时必须保留模型、版本、环境、时间、比较基线和量词，也没有显式禁止从单一条件外推整个方案。

## Previous Behavior

要求区分来源主张、实际行为和迁移推断，并一般性地识别情境限制；具体哪些限定必须保留，由执行 Agent 自行判断。

## New Behavior

压缩来源主张前，保留会影响含义的对象、模型或版本、环境、时间、比较基线和限定词；无法确认的范围标为未知。单一条件下的结果只作为该条件的证据，并与底层设计是否可迁移分开评价。Source 与 Extraction 模板同步提醒范围保真。

## Reason

把抽象的“考虑情境”转化为可执行的不变量，避免摘要链条逐步扩大经验性结论的适用范围。

## Alternatives Considered

没有增加固定评分、强制引用格式或复杂状态机；这些做法会增加负担，也不能直接保证语义范围正确。采用两条窄规则和模板提示即可覆盖已观察到的缺陷。

## User Confirmation

用户在查看根因诊断和拟议规则后明确要求：“修复技能缺陷，并修复我们一开始讨论的问题”。
