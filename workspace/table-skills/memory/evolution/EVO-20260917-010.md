# Evolution

## Trigger

用户指出原名称已不能准确表达经过多轮演化后的 Skill，并确认采用推荐名称 `chat-research-stand-in`。

## Problem

`web-task-stand-in` 强调网页任务，容易被理解为普通浏览或浏览器自动化；当前 Skill 的核心实际上是把有界研究任务委派给独立 ChatGPT 桌面聊天，并负责等待、回收和验证。

## Previous Behavior

Portable Skill 的目录、YAML `name`、标题和短描述均使用 `web-task-stand-in` / `Web Task Stand-in`，当前索引也以旧名关联反馈记录。

## New Behavior

Skill 正式重命名为 `chat-research-stand-in`，标题改为 `Chat Research Stand-in`，短描述改为 `Chat-based research delegation`，主描述明确独立 ChatGPT 桌面聊天、研究委派和不导入工作过程。目录同步改名，当前索引中的 Skill 关联更新为新名称。

## Reason

新名称同时表达执行载体、任务性质和“替身”概念，并与排除普通网页浏览的边界一致。

## Alternatives Considered

`research-chat-delegate` 更正式，但弱化了用户一直采用的“替身”概念；只修改显示标题而保留旧目录和 YAML 名称会造成长期命名分裂，因此未采用。

## User Confirmation

用户明确确认采用推荐名称 `chat-research-stand-in`。
