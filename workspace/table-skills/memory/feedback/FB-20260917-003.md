# Feedback

## Skill Used

`web-task-stand-in`

## Situation

复盘首次 3DGS 文献重任务测试的 token 消耗时，讨论网页替身的核心目标和聊天会话应获得的自主权。

## What Happened

现有流程虽然把检索与分析放进 ChatGPT 聊天，但任务包规定了大量逐项输出，并将完整长报告重新读入 Codex 主会话。结果是推理工作得到了转移，主会话上下文压力却没有充分降低。

## Good Experience

聊天会话能够独立检索、选择论文、组织趋势和提出研究缺口，已经表现出承担研究子 Agent 工作的能力。

## Bad Experience

现有 Skill 对执行过程与完整回传格式约束过多，主会话重新接收了大部分细节；这与“通过 GPT 聊天检索能力分担 Codex 主会话 token 压力”的核心目标不一致。

## User Interpretation

用户明确指出：核心目的是使用 GPT 聊天的检索能力分担 Codex 主会话 token 消耗，因此可以适当向聊天会话放权，整体思路相当于调用子 Agent。

## Other Notes

“放权”目前指向检索策略、资料筛选、中间分析与自检等研究执行权；不应自动扩展为修改本地文件、联系第三方、付费操作、处理凭据或替用户作最终项目决策。
