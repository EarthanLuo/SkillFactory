# Feedback

## Skill Used

`web-task-stand-in`

## Situation

经过多轮演化，Skill 已从笼统的网页任务替身扩展为通过独立 ChatGPT 桌面聊天委派、等待、回收和验证研究任务。

## What Happened

当前名称 `web-task-stand-in` 仍强调网页任务，但实际触发对象是独立 ChatGPT 聊天，核心角色是受约束的研究子 Agent。它还包含人工创建聊天引导、宿主侧等待和结果回收，不再只是网页检索替身。

## Good Experience

`stand-in` 保留了用户最初的“替身”概念，并能表达主会话把重研究工作交给另一个聊天承担。

## Bad Experience

`web-task` 容易让使用者误以为这是普通网页浏览或浏览器自动化 Skill，与当前明确排除普通浏览、强调 ChatGPT 会话委派的边界冲突。

## User Interpretation

用户明确要求修改 Skill 名称，认为原有名称已经不准确。

## Other Notes

建议新名称突出 `chat`、`research` 与 `stand-in`。重命名需要同步 YAML `name`、标题、目录名和当前索引引用；历史反馈与演化正文应保留原名称，以维持当时事实和可追溯性。
