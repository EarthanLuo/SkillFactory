# Discussion

## Starting Point

复核网页替身省 token 结果的适用范围，并判断该局部结果是否应影响对设计思路的整体评价。

## User View

用户核验原作者 README 后确认：省 token 不理想的问题只发生在 Astar 模型；网页替身在当前仍有思路参考价值。

## Challenges

- 当前没有对其他模型、宿主或计量方式的独立实验，不能推断它们会得到相同或相反结果。
- “设计值得参考”与“性能优化已经成立”是不同判断，不能互相替代。
- 原 Source 摘要已丢失模型限定，导致 Extraction 继承并放大了范围错误。

## What Changed

将原先接近方案级的负面判断收窄为 Astar 模型下的局部观察，并恢复网页替身作为候选设计思路的地位。

## Agreement

局部性能失败不能外推为网页替身整体无效；同时，当前证据也不足以把它写成已验证的通用省 token 方案。后续评价必须按模型与宿主保留证据范围。

## Unresolved

- 其他模型上的 token、延迟、恢复质量和操作成本尚未验证。
- 是否在后续工作中实际测试网页替身，尚未作出决定。

## Decision

`UNRESOLVED`

保留其设计参考价值并修正错误泛化，但不替用户作出采用或测试决定。
