# Evolution

## Trigger

The first real use was effective in sequence but too verbose in context.

## Problem

The old Skill treated background as broadly necessary.

## Previous Behavior

Provide a short project frame before the update.

## New Behavior

Match context to listener familiarity: one or two sentences for a familiar listener; the minimum interpretive context for an unfamiliar listener.

## Reason

Preserve decision clarity without repeating known information.

## Alternatives Considered

Removing context entirely was rejected because new listeners still need orientation.

## User Confirmation

The user confirmed the audience-aware context rule and retaining anomaly → judgment → next step.
